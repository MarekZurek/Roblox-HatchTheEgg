# Redakcja dokumentacji HatchTheEgg

Dokumentacja opisuje reguły, dane referencyjne, decyzje projektu i plan przyszłej realizacji. N/S nie oznaczają testów implementacji HatchTheEgg; R oznacza zatwierdzoną decyzję, P propozycję, H historię.

W redakcji zachowano rozdzielenie tych statusów. Usunięto opisy pochodzenia materiałów i prywatne odnośniki. W dokumentach 17–21 zmieniono wyłącznie opisy; parametry, obliczenia i odłożony status bilansu pozostają bez zmian. Nie uruchamiano symulacji ani implementacji gry.

Dawne raporty procesu i zapisane hashe dotyczą wersji ocenionych przed redakcją; ich status PASS nie potwierdza bieżącej treści. Bieżące reguły: [CURRENT_SPEC](CURRENT_SPEC.md). Plan pracy: [workflow](workflow/README.md).
