# Regresje #66–70

Uruchom `.tools/lune-0.11.1/lune.exe run tests/farm_gaps/run.luau` lub pełny tools/test.ps1 -MutationChecks -PythonExecutable python.

144 asercje: autorytatywne rekordy dronów/paczek i nieaktywny pusty kanał; FV z Accounting Tricks, awans i kalendarz; hold z kontrolowanym zegarem; IHR Sharing oraz RNG/checkpoint; bramka stacji i świeży stan zapisu. Równania oczekiwań są niezależne od funkcji testowanych. Fixture nie zatwierdza tempa progresji lub parametrów monetyzacji.

Testy wykonują rzeczywiste moduły, Main.server z kontrolowanymi usługami oraz ClientBootstrap i kontrolkę FarmPlotBuilder. Nie wykonują natywnego Main.client w Studio. Sześć mutacji jest częścią tests/game_behavior/mutation_check.py. [Zakres i ograniczenia](../../docs/workflow/farm_gaps_66_70.md).
